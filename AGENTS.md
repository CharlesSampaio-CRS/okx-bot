# OKBot — notas para agentes

## Mantra

**Toda alteração de produto atualiza a documentação** em `#/docs`:

- Narrativa: `static/index.html` → `#page-docs`
- Dicionário pesquisável: `DOCS_GLOSSARY` (+ chips `DOCS_CHIPS`) em `static/app.js`

A doc é **pesquisável** (busca, chips, aliases, FAQ). Manter rica e útil — não só um resumo fraco.

Regra Cursor: `.cursor/rules/docs-mantra.mdc` (`alwaysApply: true`).
